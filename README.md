# KEGE Reader (kompege-pip)

Расширение Firefox для **kompege.ru**: адаптивная вёрстка страниц заданий +
PiP-окошко с задачей поверх окон.

## Что делает

1. **Fluid-вёрстка.** На страницах с задачами (`/task…`) текст, таблицы,
   `<pre>`, картинки и KaTeX-формулы перестают вылезать за край окна:
   ширины `width="1400"` и т.п. гасятся, колонка сужается под окно,
   горизонтального скролла нет.
2. **Кнопка PiP у каждого номера.** Рядом с каждым номером задачи в списке
   появляется кнопка `▶`. Клик открывает **отдельное окно поверх всех окон**
   (нативный Firefox Picture-in-Picture) с кадром этой задачи.
3. **Работа в PiP-окне:**
   - `Alt+↑/↓` — прокрутка задачи в окне,
   - `Alt+←/→` — переключение номера задачи,
   - кнопка разворота в панели — крупнее/меньше кадр,
   - `A-` / `A+` — зум текста (сохраняется).
4. Нижняя панель: `⤢` разворот, `A-/A+`, `▶ PiP` для текущей задачи.

Рендер задачи в видео-поток делает собственный мини-рендерер (`lib/kp-render.js`,
canvas + captureStream) — без внешних библиотек, работает в content-script
изолированном мире.

## Установка

### Быстрый способ (временное расширение, сбрасывается после перезапуска Firefox)
1. `about:debugging#/runtime/this-firefox`
2. «Загрузить временное дополнение…» → выбрать `dist/kompege-pip.xpi`
   (или папку `dev/ffext/` — там тот же код + разрешение localhost для разработки)

### Постоянный способ
Подписанный XPI ставится «Установить дополнение из файла…» и живёт постоянно.
Подписать бесплатно можно через AMO (developer.mozilla.org, публикация Unlisted —
модерация не нужна, получаем подписанный файл).

Для Firefox Developer Edition / ESR можно отключить подпись:
`about:config → xpinstall.signatures.required = false`.

## Сборка / разработка

```bash
python3 dev/build.py        # dist/kompege-pip.xpi + dev/ffext (с localhost)
python3 dev/mockserver.py 8899 &   # мок kompege для тестов
python3 dev/test_e2e.py     # полный E2E (geckodriver:14445 + headless Firefox)
bash dev/run_ff.sh          # headless Firefox: Marionette 29313, CDP 9333
```

E2E проверяет: fluid без горизонтального скролла, работу фикса против vanilla
(1633px > 1280px), кнопки PiP, открытие PiP, рендер кадра, прокрутку,
переключение задач, зум. Текущий статус: 13/13 PASS.

## Известные ограничения
- В Firefox PiP-окно — нативное: поверх окон, перетаскивается, ресейзится;
  кнопки «переключить задачу» в самом окне нет (горячие клавиши работают,
  когда окно активно).
- Рендерер текстовый: сложные фоны/тени не рисует (заданиям это не нужно).
- Главная/курсы сайта вёрсткой не трогаются (оверрайды включаются только
  на страницах с задачами).
